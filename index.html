Mengapa Diskriminan (D = b² - 4ac) Menentukan Jenis Akar?

Berdasarkan Rumus Kuadrat (Rumus ABC): x = (-b ± √D) / (2a) , suku di dalam tanda akar kuadrat adalah diskriminan D = b² - 4ac.

1. Jika D > 0

Nilai √D menghasilkan bilangan real positif. Operasi tanda ± menghasilkan dua nilai berbeda: x₁ = (-b + √D)/2a dan x₂ = (-b - √D)/2a. Parabola memotong sumbu-X di dua titik.

2. Jika D = 0

Nilai √0 = 0. Operasi -b ± 0 sama dengan -b. Akibatnya, kedua akar berhimpit: x₁ = x₂ = -b/(2a). Parabola menyinggung sumbu-X di tepat 1 titik yang juga merupakan titik puncaknya.

3. Jika D < 0

Akar kuadrat dari bilangan negatif (√D dengan D < 0) tidak terdefinisi pada himpunan bilangan real ℝ, melainkan menghasilkan bilangan imajiner i√|D|. Oleh karena itu, kurva tidak pernah menyentuh maupun memotong sumbu-X.
